# শাহিন সরকার | রেজুমে

বাংলা ভাষায় তৈরি একটি ওয়ানপেজ রেজুমে/পোর্টফোলিও ওয়েবসাইট। Next.js এবং Tailwind CSS দিয়ে তৈরি, Vercel এ ডিপ্লয় করার জন্য প্রস্তুত।

## কনটেন্ট এডিট করবেন যেভাবে

সব প্লেসহোল্ডার কনটেন্ট (`[ ]` ব্র্যাকেটে লেখা অংশ) একটি জায়গায় রাখা আছে:

- `src/data/resume.ts` — প্রোফাইলের তথ্য, কুইক ফ্যাক্টস এবং প্রতিটি সেকশনের (ব্যক্তিগত তথ্য, শিক্ষা, অভিজ্ঞতা, দক্ষতা ইত্যাদি) লেবেল ও মান এখানে।

এই ফাইলে পরিবর্তন আনলেই পুরো সাইট আপডেট হয়ে যাবে, আলাদা কম্পোনেন্ট এডিট করার দরকার নেই।

## লোকাল ডেভেলপমেন্ট

```bash
npm install
npm run dev
```

তারপর ব্রাউজারে `http://localhost:3000` খুলুন।

## বিল্ড

```bash
npm run build
```

## ডিপ্লয়

Vercel এ রিপোজিটরি ইমপোর্ট করলেই ফ্রেমওয়ার্ক অটো-ডিটেক্ট হয়ে ডিপ্লয় হয়ে যাবে, কোনো এক্সট্রা কনফিগারেশন লাগবে না।

## PDF — সম্পূর্ণ অটোমেটিক

"PDF ডাউনলোড" বাটনটি `public/shahin-sarker-biodata.pdf` ফাইলটা সরাসরি ডাউনলোড করায়। এই ফাইলটা **প্রতিবার `npm run build` চলার সময় নিজে থেকেই নতুন করে তৈরি হয়** (`package.json` এর `postbuild` স্ক্রিপ্ট দিয়ে) — অর্থাৎ `src/data/resume.ts` এ কনটেন্ট বদলে GitHub এ পুশ করলে Vercel যখন অটো-ডিপ্লয় করবে, PDF ও নতুন কনটেন্ট নিয়ে অটোমেটিক আপডেট হয়ে যাবে। আলাদা করে কিছু চালাতে হবে না।

এটা একটাই লম্বা পেজের আসল টেক্সট-ভিত্তিক (vector) PDF — স্ক্রিনশট নয়, তাই টেবিল কোথাও পেজ-ব্রেকে কাটা পড়ে না এবং যেকোনো সাইজে জুম করলেও লেখা পরিষ্কার থাকে।

স্থানীয়ভাবে (লোকালি) নিজে থেকে জেনারেট করে দেখতে চাইলে:

```bash
npm install   # playwright সহ সব ডিপেন্ডেন্সি বসে যাবে
npm run build # build শেষে postbuild নিজে থেকেই PDF বানাবে
```
